# penlight

penlight は、イベント連動と参加型演出に使うウィジェットです。

## 主な用途

- 抽選 / 判定演出
- コメント連動リアクション
- 盛り上げエフェクト

## 主要設定項目

- トリガー条件
- 実行アクション
- 表示強度（サイズ / 速度 / 数量）
- 色設定
- テスト操作

## 基本設定の流れ

1. 発火条件を決める。
2. 実行アクションを選ぶ。
3. 演出パラメータを調整する。
4. 誤発火がないかテストする。
5. 本番向けに微調整する。

## 配信前チェック

- 誤反応しやすい条件になっていない
- 同時発火でも見づらくならない
- 操作手順が明確
