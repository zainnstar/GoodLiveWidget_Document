# GreetingCounter

GreetingCounter は、あいさつや参加回数のカウント表示に向くカウンター系ウィジェットです。

## 主な用途

- 配信冒頭のあいさつ人数表示
- 参加回数の記録表示
- 目標到達の進捗共有

## 主要設定項目

- 増減 / リセット操作
- 現在値
- ステップ値
- ラベル文言
- 文字位置
- テキスト色 / 数値色
- フォントサイズ / フォント
- 数字揃え
- デザインエフェクト

## 基本設定の流れ

1. ラベルと初期値を設定する
2. ステップ値を運用に合わせる
3. 増減ボタンで操作感を確認する
4. 色とフォントを可読性優先で調整する
5. 本番前にリセットして開始する

## 配信前チェック

- 初期値が前回の値のまま残っていない
- 視認しやすい表示位置になっている
- 数値桁が増えても崩れない幅になっている
