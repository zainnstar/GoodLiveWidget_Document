# streaming-multi-counter

streaming-multi-counter は、数値や配信統計を表示するウィジェットです。

## 主な用途
- 目標進捗の可視化
- リアルタイム指標の共有
- 参加型企画のカウント表示

## 主要設定項目
- 表示ソース
- 数値フォーマット
- ラベル文言
- 文字色 / 数値色
- フォントサイズ / フォント

## 基本設定の流れ
1. 表示するデータソースを決める。
2. フォーマットとラベルを調整する。
3. フォントと色を調整する。
4. レイアウトのサイズと位置を調整する。
5. Preview で桁増加時の見やすさを確認する。

## 配信前チェック
- 値が正しく更新される
- 桁が増えても崩れない
- 文字コントラストが十分
