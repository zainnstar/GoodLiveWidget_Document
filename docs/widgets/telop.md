# telop

telop は、テキストや進行情報を整理して表示するウィジェットです。

## 主な用途
- 案内情報の表示
- 進行項目の整理
- スケジュール / メモ表示

## 主要設定項目
- テキスト / 項目内容
- 順序とレイアウト
- フォントサイズ / フォント
- 色設定
- 位置と余白

## 基本設定の流れ
1. 表示内容を入力する。
2. 順序とレイアウトを整える。
3. 文字設定を調整する。
4. 位置と余白を調整する。
5. Preview で可読性を確認する。

## 配信前チェック
- 情報量が過多でない
- 画面端で切れていない
- モバイルサイズでも読める
