# CommentOverlay

CommentOverlay は、コメントを配信画面上に重ねて表示するウィジェットです。

## 主な用途

- コメント可視化
- リアクションの活性化
- 会話ログの補助表示

## 主要設定項目

- レイアウト方向（縦 / 横）
- 成長方向（上 / 下 / 左 / 右）
- 表示要素（本文 / 投稿者名 / アイコン / 投げ銭額）
- 取り込み種別（通常コメント / 投げ銭コメント）
- 最大表示件数
- フォントサイズ / フォント

## 基本設定の流れ

1. レイアウト方向と成長方向を決める
2. 必要な表示要素だけを有効にする
3. 取り込みたいコメント種別を選ぶ
4. 最大表示件数を画面サイズに合わせる
5. Comment Test で流れ方を確認する

## 配信前チェック

- 最大表示件数が多すぎて画面を塞いでいない
- 投げ銭表示の有無が企画方針と一致している
- 文字サイズがモバイル視聴でも読める

## よくあるつまずき

- コメントが窮屈: 最大表示件数を下げる
- 情報量が多すぎる: 投稿者名や投げ銭額の表示を絞る
- 期待した方向に流れない: 成長方向を再設定する
