# BirthdayChecker

BirthdayChecker は、誕生日チェック企画を管理しやすく表示するウィジェットです。

## 主な用途

- 誕生日紹介コーナー
- 月別の記念日チェック
- 視聴者参加型の記録企画

## 主要設定項目

- うるう日を含める
- チェック済み色
- 未チェック色
- 月ごとの有効化
- 日ごとのチェックON/OFF
- フォントとデザイン設定

## 基本設定の流れ

1. 対象月を有効化する
2. チェック対象の日付を選ぶ
3. チェック済み / 未チェックの色を調整する
4. 配置サイズを調整して見切れを防ぐ
5. Preview で表示確認する

## 運用のコツ

- うるう日の扱いを先に決めておく
- 色差を大きめにして状態を判別しやすくする
- 進行前に対象月の有効化漏れを確認する
