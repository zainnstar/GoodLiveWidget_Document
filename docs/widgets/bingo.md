# ビンゴ

ビンゴは、ビンゴ企画の進行を画面表示するためのウィジェットです。

## 主な用途

- 参加型チャレンジ企画
- 進行中の達成状況表示

## 主要設定項目

- グリッドサイズ
- マス内容
- 強調色やデザイン
- フォント関連
- 共通エフェクト連動
- Generate / Reset 操作

## 基本設定の流れ

1. グリッドサイズを決める
2. マス内容を埋める
3. Generate ボタンで表示内容を反映する
4. 配置とサイズを調整する
5. 本番前に Reset ボタンの動作も確認する

## よくあるつまずき

- 文字が潰れる: グリッドサイズを下げるか表示サイズを広げる
