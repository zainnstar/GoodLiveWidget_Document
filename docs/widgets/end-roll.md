# EndRoll

EndRoll は、配信終了時のクレジット表示を行うウィジェットです。

## 主な用途

- エンディング演出
- 参加者 / 支援者の表示
- 配信締めの定型メッセージ表示

## 主要設定項目

- 開始メッセージ
- 終了メッセージ
- 再生時間
- 背景色
- Start / Pause / Reset 操作
- 取り込み元フィルタ（通常 / 支援 / メンバー関連）
- ユーザーアイコン表示
- 終了後背景維持

## 基本設定の流れ

1. 開始・終了メッセージを作る
2. 再生時間を配信尺に合わせる
3. 表示対象フィルタを選ぶ
4. Start / Pause / Reset をリハーサルで確認する
5. 本番前に表示状態を Idle に戻す

## 配信前チェック

- メッセージ文面が当日の配信内容と一致している
- フィルタ条件が意図通り
- EndRoll が再生中のまま残っていない
