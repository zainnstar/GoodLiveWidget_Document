# FirstCommentExtensionTimer

FirstCommentExtensionTimer は、コメントやイベントで延長されるタイマーを表示するウィジェットです。

## 主な用途

- コメント連動延長企画
- 耐久配信の時間管理
- イベント条件付きの延長演出

## 主要設定項目

- タイトル文言
- タイマー実行中フラグ
- 残り秒数 / 最大秒数 / 初期秒数
- リセット
- 初回コメントで延長
- メンバー加入で延長
- スーパーチャットで延長
- いいね増加で延長
- 登録者増加で延長

## 基本設定の流れ

1. 初期秒数と最大秒数を決める
2. 延長トリガーを有効化する
3. 各トリガーの加算秒数を決める
4. タイトル文言と表示サイズを調整する
5. リセット動作を含めてリハーサルする

## 配信前チェック

- 残り秒数が初期秒数から開始する
- 延長条件が企画ルールと一致する
- 最大秒数が短すぎて演出が成立しない状態でない
