# Checklist

Checklist は、進行手順や確認項目をチェック形式で表示するウィジェットです。

## 主な用途

- 配信前チェック項目の共有
- 企画進行の手順管理
- タスク消化の見える化

## 主要設定項目

- チェック項目の内容
- 項目の並び順
- 表示フォント / サイズ
- 色やデザイン
- 文字アクション / デザインエフェクト

## 基本設定の流れ

1. 必要なチェック項目を登録する
2. 配信で使う順番に並べる
3. 見出しと本文の文字サイズを調整する
4. 配置と枠サイズを確定する
5. リハーサルで実際にチェック操作を確認する

## 運用のコツ

- 1項目は短い文にして視認性を上げる
- 進行順と画面表示順を一致させる
- 配信ごとにテンプレ項目を見直す
