# CalendarWeek

CalendarWeek は、1週間単位で予定を見せるためのウィジェットです。

## 主な用途

- 週間配信予定の表示
- 今週の企画案内
- 定期配信日の見える化

## 主要設定項目

- 週の開始曜日
- 曜日表示形式（英語 / 日本語）
- 実日付を使う
- 曜日ラベル表示
- 日付ラベル表示
- 週オフセット（前週 / 次週）

## 基本設定の流れ

1. 週の開始曜日を決める
2. 曜日・日付ラベルの表示方針を決める
3. 必要なら週オフセットで対象週を切り替える
4. フォントと配色を調整する
5. Preview で読みやすさを確認する

## 運用のコツ

- 予定変更が多い場合は更新タイミングを固定する
- 月またぎ週は表示崩れがないか事前確認する
- 小さい表示サイズでは項目を省略して可読性を優先する
