# FocusLines

FocusLines は、集中線演出を表示するウィジェットです。

## 主な用途

- 見せ場の強調
- 場面転換のインパクト演出
- テロップや判定結果の注目誘導

## 主要設定項目

- 線本数
- 線の太さ
- 内側カット率
- 回転速度
- 線色
- 中心色
- 合成モード

## 基本設定の流れ

1. 線本数と太さを決める
2. 内側カット率で中心の抜け感を調整する
3. 回転速度を演出強度に合わせる
4. 色を背景と干渉しないよう調整する
5. 本番解像度でちらつきと可読性を確認する

## 配信前チェック

- 情報系ウィジェットの可読性を邪魔していない
- 線が多すぎて画面ノイズ化していない
- 高速回転で酔いやすくなっていない
