# paint

paint は、素材表示や背景演出に使うビジュアル系ウィジェットです。

## 主な用途

- シーンの雰囲気づくり
- 素材表示
- 場面転換演出

## 主要設定項目

- 素材読み込み / クリア
- 表示サイズ / 位置
- 色と透明度
- 速度 / ループ挙動
- リセット操作

## 基本設定の流れ

1. 使用素材を準備する。
2. 位置とサイズを調整する。
3. 演出強度を調整する。
4. 他ウィジェットとのバランスを確認する。
5. Preview で最終確認する。

## 配信前チェック

- 素材が正しく読み込まれている
- 主情報を隠していない
- 描画負荷が安定している
