# Dice

Dice は、最小値から最大値の範囲でランダム値を表示するウィジェットです。

## 主な用途

- 抽選演出
- 罰ゲーム / ご褒美判定
- 参加型ミニゲーム

## 主要設定項目

- Roll ボタン
- 最小値
- 最大値
- サイコロ面の色
- 目（文字）の色

## 基本設定の流れ

1. 最小値と最大値を設定する
2. 色を配信テーマに合わせる
3. Roll で演出タイミングを確認する
4. 配置とサイズを調整する
5. 本番前に値範囲を再確認する

## 配信前チェック

- 最小値と最大値が逆転していない
- 判定ルールに合った数値範囲になっている
- 背景色と目の色が見分けやすい
