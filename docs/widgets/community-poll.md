# CommunityPoll

CommunityPoll は、投票項目と票数を表示するアンケート用ウィジェットです。

## 主な用途

- 視聴者アンケート
- 企画中の多数決
- 話題ごとの反応比較

## 主要設定項目

- 選択肢の追加 / 削除
- 各選択肢ラベル
- 票数の手動調整
- 票数リセット
- 文字色
- フォントサイズ / フォント

## 基本設定の流れ

1. 選択肢を作成する
2. ラベルを短く分かりやすく整える
3. 票数の初期値を確認する
4. 文字色とフォントを見やすく調整する
5. 配信中は必要に応じて票数を更新する

## 配信前チェック

- 選択肢の文言が重複していない
- 票数が前回配信の値のまま残っていない
- 文字サイズがスマホ視聴でも読める
