# AttendanceStamp

AttendanceStamp は、視聴者の参加記録をカレンダー形式で見せるためのウィジェットです。

## 主な用途

- 参加日数の可視化
- 常連視聴者へのリアクション演出
- 月ごとの参加状況共有

## 主要設定項目

- 年 / 月
- スタンプ絵文字（手入力 + プリセット）
- グリッド色
- 曜日表示形式（英語 / 日本語）
- アイコン表示
- 常時表示
- 自動非表示秒数
- スタンプアニメーションのテスト

## 基本設定の流れ

1. Widget List パネルで AttendanceStamp を追加する
2. Inspector の年・月を配信運用に合わせる
3. スタンプ絵文字とグリッド色を調整する
4. 曜日形式と表示オプションを決める
5. テストボタンで表示演出を確認する

## 配信前チェック

- 年月が今月設定になっている
- スタンプ絵文字が配信テーマに合っている
- 自動非表示時間が短すぎない

## よくあるつまずき

- スタンプが見づらい: グリッド色と絵文字のコントラストを上げる
- 表示が消える: 常時表示を有効化するか自動非表示秒数を延ばす
- 曜日表記が意図と違う: 曜日形式を英語/日本語で切り替える
