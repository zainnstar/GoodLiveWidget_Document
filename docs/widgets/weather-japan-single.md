# weather-japan-single

weather-japan-single は、天候情報と天候演出を表示するウィジェットです。

## 主な用途
- 天気コーナー表示
- 季節感の演出
- 地域情報の共有

## 主要設定項目
- 表示対象エリア
- 更新間隔
- 表示要素（地域名 / 気温 / 出典）
- 文字設定
- 色設定

## 基本設定の流れ
1. 表示対象エリアを選ぶ。
2. 更新間隔を設定する。
3. 必要な表示要素を有効にする。
4. 文字設定と色を調整する。
5. Preview で可読性を確認する。

## 配信前チェック
- 対象地域の選択漏れがない
- 更新間隔が短すぎない
- 情報が読みやすい
