# CalendarMonth

CalendarMonth は、月カレンダーを画面表示するためのウィジェットです。

## 主な用途

- 月予定の告知
- イベント日程の共有
- 配信スケジュールの固定表示

## 主要設定項目

- 週の開始曜日
- 曜日表示形式（英語 / 日本語）
- 実カレンダー日付を使う
- 月オフセット（前月 / 次月移動）
- 配色・フォント・デザイン

## 基本設定の流れ

1. 週の開始曜日を設定する
2. 曜日表記を選ぶ
3. 必要なら月オフセットで表示月をずらす
4. 配色とフォントを整える
5. 画面上で読みやすいサイズに調整する

## 運用のコツ

- 予定が多い月は表示サイズを広めに確保する
- 表示月を固定運用する場合は更新担当を決める
- 月初に表示内容を見直す運用を作る
