# カウンター

カウンターは、数値を手動または配信連携で表示するウィジェットです。

## 主な用途

- 目標達成数の可視化
- 企画進行カウンター
- 配信統計値の表示

## 主要設定項目

- 増減 / リセット操作
- 現在値
- ステップ値
- ラベル文字
- 表示フォーマット（カンマ区切りなど）
- 文字位置 / 文字色 / 数値色
- フォントサイズ / フォントスタイル

## 運用のコツ

- 桁が増える想定で表示幅に余白を持たせる
- 連携モードではラベルを自動値に合わせて更新する
- 高頻度更新ではフォント演出を控えめにする
