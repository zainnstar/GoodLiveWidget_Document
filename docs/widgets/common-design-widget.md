# CommonDesign

CommonDesign は、共通デザインをまとめて適用するためのウィジェットです。

## 主な用途

- 全体トーンの統一
- 背景・枠・影の共通管理
- シーン切り替え時のデザイン差し替え

## 主要設定項目

- デザイン選択
- 塗り色スロット
- グラデーション色
- 線色 / 線幅
- 影の有効化と色
- 影オフセット

## 基本設定の流れ

1. Common Design パネルで使うデザインを選ぶ
2. CommonDesign で色スロットを微調整する
3. 線幅や影の強さを調整する
4. 他ウィジェットとの重なり順を確認する
5. シーン別に設定を保存して使い分ける

## 運用のコツ

- 先に全体デザインを決めてから個別色を調整する
- 影は弱めから調整して可読性を維持する
- 変更時はPreviewで文字視認性を必ず確認する
