# ウィジェット一覧

GoodLiveWidget で使えるウィジェットの一覧です。  
各ページでは、用途と基本設定手順を公開向けに整理しています。

## 使い始めの流れ

1. [ウィジェット一覧 パネル](../panels/widget-list.md)でウィジェットを追加
2. [インスペクタ パネル](../panels/inspector.md)で内容を調整
3. [トランスフォーム パネル](../panels/transform.md)で配置調整
4. OBSか[プレビュー パネル](../panels/preview.md)で最終確認
