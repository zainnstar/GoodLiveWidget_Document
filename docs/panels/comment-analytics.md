# コメント分析パネル

コメント分析パネルは、配信中に記録されたコメント履歴を配信単位で確認する画面です。

## 事前準備

- [設定パネル](settings.md)で「コメントを DB に記録する」をONにする
- [配信連携パネル](streaming-integration.md)で実際に配信接続する

## できること

- 配信チャンネル選択
- 配信セッション選択
- チャンネルIDで絞り込み
- 本文検索
- コメント一覧の確認（時刻、表示名、種別、有料、フラグ）
- ページ切り替え

## 基本操作

1. 配信チャンネルを選ぶ
2. 確認したい配信セッションを選ぶ
3. 必要に応じて「チャンネル ID で絞り込み」「本文検索」を使う
4. 一覧をページ送りしながら確認する

## 一覧で確認できる情報

- 時刻
- 表示名
- チャンネル ID
- 種別
- 本文
- 有料（スーパーチャットなど）
- フラグ（初コメ、モデレーター、認証、メンバー など）

## 活用例

- 配信後にキーワード反応を振り返る
- 初回参加者や常連反応を比較する
- 有料コメントやイベント系コメントの傾向を確認する

## よくあるつまずき

- 画面が空: コメント記録がOFFの可能性がある
- 配信セッションが出ない: 対象チャンネルで記録付きの配信がまだない
