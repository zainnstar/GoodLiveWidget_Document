# パネル一覧

GoodLiveWidget の作業は、左側の各パネルを組み合わせて進めます。  
このページでは、配信準備から本番確認までの流れで使い分けできるように、各パネルの役割を整理しています。

## はじめて使うときの順番

1. [設定 パネル](settings.md)で表示言語・解像度・ポートを確認する
2. [接続 パネル](connection.md)で OBS 連携を有効にする
3. [ウィジェット一覧 パネル](widget-list.md)でウィジェットを追加する
4. [インスペクタ パネル](inspector.md)と[トランスフォーム パネル](transform.md)で見た目と配置を調整する
5. [プレビュー パネル](preview.md)で最終表示を確認する

## 配信連携を使うときの順番

1. [配信連携 パネル](streaming-integration.md)で配信URLを接続する
2. [コメントテスト パネル](comment-test.md)で本番前の反応確認をする
3. [視聴者分析 パネル](viewer-analytics.md)と[コメント分析 パネル](comment-analytics.md)で振り返る

## 各パネルの役割

- [ウィジェット一覧 パネル](widget-list.md): ウィジェットの追加、レイヤー管理、フォルダ整理
- [インスペクタ パネル](inspector.md): 選択中ウィジェットの詳細設定
- [トランスフォーム パネル](transform.md): キャンバス上での位置・サイズ・回転の調整
- [プレビュー パネル](preview.md): ブラウザ描画での最終見た目確認
- [共通デザイン パネル](common-design.md): 共通デザイン・共通フォント・共通画像の一括運用
- [設定 パネル](settings.md): アプリ全体設定（表示、配信連携、解像度など）
- [接続 パネル](connection.md): OBS ブラウザソース接続の管理
- [配信連携 パネル](streaming-integration.md): YouTube/Twitch 連携、ライブコメント確認
- [コメントテスト パネル](comment-test.md): テストイベントの送信
- [視聴者分析 パネル](viewer-analytics.md): 視聴者の参加傾向確認
- [コメント分析 パネル](comment-analytics.md): コメント履歴の絞り込み確認
- [ログ パネル](logs.md): 操作ログの確認とコピー
