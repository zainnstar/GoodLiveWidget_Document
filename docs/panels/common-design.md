# 共通デザインパネル

共通デザインパネルは、複数ウィジェットに共通の見た目を適用するためのパネルです。

## できること

- 共通デザインのテンプレート指定
- 共通フォントの指定
- 新規追加ウィジェットへの自動適用設定
- 「共通デザインを全体に適用」で一括反映

## セクション構成

- 共通デザイン: 色、形状、デザインエフェクトの共通化
- 共通フォント: フォントファミリー、フォントアクションの共通化

## 基本操作

1. 共通デザインを調整する
2. 必要なら「追加するウィジェットにこのデザインを適用する」をONにする
3. 既存ウィジェットにも反映したい場合は「共通デザインを全体に適用」を実行する

## 注意点

- 全体適用は、各ウィジェットで個別に調整した色や見た目を上書きする
- 一括反映する前に、プレビューパネルで代表ウィジェットを確認する

## 運用のコツ

- 初期段階で共通ルールを作ってから個別調整に入ると、作業時間が大きく減る
- テーマ変更時は先に共通デザインを調整し、必要に応じて個別にインスペクタで仕上げる
