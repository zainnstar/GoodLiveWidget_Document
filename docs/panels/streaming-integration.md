# 配信連携パネル

配信連携パネルは、配信サービスとの接続とライブコメント確認を行う画面です。

## できること

- URL入力によるサービス自動判定（YouTube/Twitch）
- 複数配信行の追加
- 配信行の並べ替え
- 配信ごとの接続状態確認
- コメントをウィジェットへ反映するかの切り替え
- YouTubeログインの起動
- 接続中ライブのチャットを別ウィンドウで開く
- コメント一覧とユーザー一覧の確認

## 画面構成

- 接続テーブル: URL、タイトル、状態、ポップアウト、反映ON/OFF、削除
- オプション: 取得間隔、Twitch ニック名、Twitch OAuth、YouTubeログイン
- コメント: 受信コメントのリアルタイム表示
- ユーザー: この配信でのコメント回数一覧

## 基本操作

1. 「配信追加」で行を作る
2. URLを入力して接続する
3. 状態が「接続済み」になったらコメント表示を確認する
4. 必要な行だけ「ウィジェット」列をONにする
5. 不要な行は削除する

## URL入力のポイント

- YouTube はハンドルURLまたはライブURLに対応
- Twitch はチャンネルURLに対応
- ニコニコは形式判定のみで、現在は接続不可

## 運用のコツ

- 複数配信を同時に扱う場合は、色とタイトルで区別する
- 本番前に [コメントテストパネル](comment-test.md) で反応確認しておく
- 配信限定コメントを扱う場合は、先に YouTube ログインを済ませる

## よくあるつまずき

- URLを入れても接続されない: URL形式とネットワーク接続を確認する
- コメントがウィジェットに出ない: 該当行の「ウィジェット」チェックを確認する
- チャット別ウィンドウが開けない: 接続済みでライブIDが確定しているか確認する
