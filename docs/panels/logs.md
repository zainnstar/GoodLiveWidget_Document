# ログパネル

ログパネルは、アプリ内で発生した操作や接続状況を時系列で確認するための画面です。

## できること

- ログの一覧表示
- 選択範囲だけコピー
- 全ログを一括コピー
- 「ログをクリア」で表示を整理

## 使いどころ

- OBS 接続や配信連携がうまくいかないとき
- 操作後に何が起きたか確認したいとき
- 問題の状況をサポートへ共有するとき

## 基本操作

1. 問題が起きた直後に ログパネル を開く
2. 必要な行だけドラッグ選択して「選択をコピー」する
3. まとまった共有が必要な場合は「ログをすべてコピー」を使う
4. 切り分けをやり直す前に「ログをクリア」で初期化する

## 運用のコツ

- 再現テスト前に一度クリアしておくと原因が追いやすい
- 変更を1つずつ試し、ログの差分を見ると切り分けしやすい
- 接続系トラブルは [接続パネル](connection.md) と合わせて確認する
- ただし、表示するログ情報をあまり設定していないため、あまり情報が無い点に注意
- クラッシュした場合はログではなく、userdata/crash_reports フォルダ内の最新のクラッシュレポートを確認する
