# プレビューパネル

プレビューパネルは、ブラウザ描画に近い状態で最終表示を確認するための画面です。

## できること

- 「ブラウザプレビューを有効」でプレビュー表示をON/OFF
- 「すべて表示」で全体表示へ戻す
- インスペクタの単体プレビュー指定を反映して確認
- プレビュー枠線や背景色を反映した見た目確認

## 基本操作

1. 「ブラウザプレビューを有効」を ON にする
2. 画面内でウィジェット表示を確認する
3. 必要に応じて インスペクタ から単体プレビューへ切り替える
4. 全体確認に戻す場合は「すべて表示」を押す

## ズームについて

- 通常プレビューでは 100% 表示固定
- デザイン一覧表示や YouTube ログイン表示のときはズーム調整が可能

## 運用のコツ

- プレビュー画面はPC負荷が高いので、調整時以外はOFFにしておく
- 配信直前は、文字の可読性と重なりを必ず確認する
- レイアウト調整は トランスフォームパネル、色や見た目調整は インスペクタパネル と分担する

## よくあるつまずき

- 何も表示されない: プレビューが ON か、対象ウィジェットが存在するか確認する
- 単体表示のまま戻らない: 「すべて表示」を押す
- 表示が重い: 調整時だけONにして、作業しないときはOFFにする
