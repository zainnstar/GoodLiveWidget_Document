# 設定パネル

設定パネルは、アプリ全体の共通設定を管理する画面です。
できればソフトを起動したら始めに見ることをお勧めします。

## 主な設定項目

- OBS キャンバス解像度（幅・高さ・プリセット）
- OBS WebSocket ポート
- フォントサイズ
- WebSocket ポート
- テーマ
- 基本フォント
- パネル表示色（トランスフォーム背景、プレビュー背景、プレビュー枠）
- 配信連携向け設定（コメント記録、VTube Studio API、接続テスト）
- ユーザーデータフォルダを開く

## 基本操作

1. 初回はポート設定と OBS 解像度を先に確認する
2. 配信画面に合わせてテーマやフォントを調整する
3. 必要な場合のみ「コメントを DB に記録する」をONにする
4. VTube Studio を使う場合は API 利用をONにし、接続テストする

## 使い分けの目安

- 配信が映らない/連携しない: ポート設定を確認
- 見た目を整えたい: テーマ、フォント、パネル表示色を調整
- 画面サイズが合わない: OBS キャンバス解像度を調整

## 注意点

- ポート変更後は、接続先（OBS 側設定など）も同じ値に合わせる
- コメント記録を有効にすると、配信後の分析で使える履歴が増える
- 解像度を変えるとレイアウト見え方が変わるため、変更後は プレビュー確認が必要
