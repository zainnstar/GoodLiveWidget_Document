# コメントテストパネル

コメントテストパネルは、実配信につながずにテストイベントを送って動作確認する画面です。

## できること

- 通常コメントのテスト送信
- スーパーチャット（定額/自由金額/ステッカー）の送信
- メンバーシップイベントの送信
- ライブリアクション/エンゲージメントの擬似送信
- ライブメトリクス（同時視聴者数、高評価数、登録者数）の送信
- ランダムコメント送信

## 基本操作

1. プラットフォームを選ぶ
2. 投稿者情報（表示名、チャンネルID）を入力する
3. 必要なら初コメフラグやバッジを設定する
4. イベント種別を選び、内容を入力する
5. 「テスト送信」を押して反映を確認する

## 確認先

- [配信連携パネル](streaming-integration.md) のコメント欄
- コメント連動ウィジェットやカウンター系ウィジェットの反応

## 重要なポイント

- テスト送信は、分析用の通常履歴には保存されません
- 実配信未接続でもテスト送信は可能です
- Twitch は一部イベントが対象外で、通常コメント中心の確認となります

## 活用例

- 配信前の演出・連動確認
- 初コメ系の表示確認
- スーパーチャット色や見え方の確認
