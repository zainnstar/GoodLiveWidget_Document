# 視聴者分析パネル

視聴者分析パネルは、配信に参加した視聴者の傾向を振り返るための画面です。

## できること

- 配信チャンネルごとの視聴者データ確認
- 表示名やチャンネルIDで検索
- 発言数、最終コメント、配信参加回数で並び替え
- ページ切り替え
- CSV 出力

## 基本操作

1. 配信チャンネルを選択する
2. 必要に応じて検索条件を入力する
3. 並び替えを選んで傾向を確認する
4. 必要なデータをCSV出力する

## 表の見方

- 発言: コメント数
- 配信数: 参加した配信回数
- メンバー: メンバー関連情報の有無
- 最終コメント: 最後に確認されたコメント時刻

## 活用例

- 常連視聴者の把握
- 初回参加が増えた配信回の分析
- 次回配信での声かけ対象検討

## よくあるつまずき

- データが表示されない: 先に [配信連携パネル](streaming-integration.md) で配信接続を行い、リスナーが参加してから確認してください
- チャンネルが空: 配信連携データがまだ作られていない可能性がある
