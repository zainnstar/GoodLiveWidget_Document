# GoodLiveWidget

**YouTube / Twitch ライブ配信向けウィジェットオールインワン管理ソフト**

GoodLiveWidget (グッドライブウィジェット) は、 OBS オーバーレイ表示を **ひとつのアプリ** で行うためのツールです。
パネルウィンドウでウィジェットを編集し、内蔵 HTTP / WebSocket サーバー経由で OBS ブラウザソースにリアルタイム反映します。

---

## 主な特徴

- **豊富なウィジェット** — カウンター、セットリスト、コメントオーバーレイ、テロップ、お絵描きなど
- **初めてでも超簡単に使える！** — 充実のチュートリアルで、機能の追加から使い方まで丁寧に解説
- **OBSのソースをひとまとめに！** — ソフト内でたくさんの機能を使っても、OBSのソース欄をすっきり管理
- **既成のウィジェットより軽い！** — 軽量化設計のソフトに機能をまとめたから、複数ウィジェットを同時に使っても軽快に動作
- **配信連携** — YouTube / Twitch のコメント取得、視聴者・コメント分析もこれ一つで
- **プロファイル対応** — 配信内容ごとにウィジェット構成を保存・切り替え
